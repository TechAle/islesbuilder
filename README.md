# Isles Builder

A web-based **build manager and DPS calculator** for the Minecraft game **Isles**.

The calculator models the full damage pipeline — base damage, damage-type and
elemental brackets, Elemental Power, mastery, critical hits, burst, special
attacks, augments and enemy defense — and also includes the **skill tree**, so
builds can be optimized instead of guessed.

---

## Contributions

**Pull requests are not accepted.**

This project is built and maintained for **Isles version 1.0.6**. Newer game
versions may change items, abilities, formulas or mechanics, so results are not
guaranteed to match the live game.
